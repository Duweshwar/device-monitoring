# AGENT.md — Client Dashboard Specification

## 1. Overview & Objectives

The **Client Dashboard** (`/web-dashboard/client-dashboard`) is the customer-facing web portal for the Parental & Enterprise Phone Monitoring platform. It allows parents to monitor and manage their children's Android devices (Parent Mode) and enterprise clients to manage company-owned employee device fleets (Business Mode).

---

## 2. Technology Stack

- **Framework**: Vite + React 18+ (TypeScript) SPA
- **Styling**: Tailwind CSS + Shadcn UI + Lucide Icons
- **Interactive Mapping**: Leaflet.js / Mapbox GL (Live location map, geofence radius drawer, historical route playback)
- **Analytics & Charts**: Recharts / Tremor (App usage duration, screen time breakdowns)
- **HTTP Client**: Axios with JWT auth interceptors & refresh handling
- **Real-Time Feed**: Native SSE Client connecting to `/api/v1/realtime/stream`
- **State Management**: Zustand (Auth, selected device, map state) + TanStack Query (Server cache)

## 4. Key Feature Specifications

1. **Device Pairing Wizard**: Enter 6-digit pairing code generated by backend to bind new child/employee device.
2. **Live Map & Geofencing**: Displays real-time GPS marker, battery percentage, network type, and allows drawing geofence radii.
3. **Social Media Chat Viewer**: Timeline view for WhatsApp, Instagram, Telegram, Snapchat messages with sender bubble formatting.
4. **Media & Surround Player**: Gallery viewer for photos, screenshots, and custom web audio player for ambient surround recordings & voice notes.
5. **Policy & App Blocker Manager**: Toggles for app restrictions, web domain blacklisting, and schedule setting.
